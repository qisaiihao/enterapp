# 详情页分享卡片配色更新

2026-10-28：修复详情页生成诗歌卡片后，选中的配色可能被旧设置覆盖的问题。

## 原因与修改

绘制工具本来就优先使用当前分享配置的背景色和文字色。可复现的回退发生在字体预览：300ms 防抖任务保存了完整配置，期间换色后，任务会把旧配色一起写回。

详情页现在立即合并字体预览设置，防抖仅推迟重绘。颜色或字体确认触发重绘时，取消尚未执行的预览重绘，使用最新配置。颜色选择只通过 `color-change` 请求一次生成，不再额外触发一次强制重绘。

请求重绘时立即使旧绘制任务失效。等待界面更新、异步签名绘制或图片导出后，都需确认任务仍有效，避免旧任务提交画布或覆盖新预览。连续重绘请求合并为最后一次有效请求；关闭分享弹窗、离开详情页后，待执行的预览与选色重绘任务不再生成图片。

分享配色只改变生成的卡片，不写回原帖。本次未修改字体资源路径、页面字体注册逻辑或 Canvas 字体名称，无需部署云函数。
