# 首页默认筛选与排序

广场默认「显示全部」，也会恢复用户保存的「只看普通帖子」偏好。后台预加载与页面使用相同默认值。

## 显示全部

每批 10 条包含 6 条按加权时间排序的帖子、3 条随机帖、1 条高赞帖。普通帖的发布时间加 24 小时用于排序。诗歌和讨论使用原发布时间。加权时间相同时依次比较原发布时间、帖子 ID，均按降序排列。高赞位从剩余候选中选点赞数最多且至少有 1 赞的帖子。随机位由数据库抽样。候选不足或推荐查询失败时，用剩余时间序帖子补齐。兼容历史帖子和 schema v2，只选公开可见的帖子，并在选帖前排除隐藏、活动、已删除、审核未通过或屏蔽作者的帖子。

手动下拉刷新时，全部位置优先从上一批首屏之外选取。可见候选足够时整批换成 10 条不同的帖子，候选不足时先显示所有可换的帖子，再从上一批仍可见的帖子中按加权时间补齐。加载更多时用当前列表的帖子 ID 排除已出现的内容，按剩余候选重新混排。ID 仅用于本次查询，页面无需采集停留时长，也无需写入或查询浏览历史。刷新失败时保留当前已显示的列表。

## 随机刷新

在广场筛选中选择「随机刷新」，整批从可见候选中随机抽取。再次点击该选项或手动下拉都会重新抽取，优先换掉上一批首屏。向下翻页时排除当前列表已经出现的帖子。切换至「显示全部」或「只看普通帖子」退出随机模式。随机模式随当前页面保留，略缩和全文显示可独立切换。

## 接口与发布

- `getPostList` 的 `homeRanking: true` 与 `homeMix: true` 一起启用广场混排。旧客户端仅传 `homeRanking` 时继续按加权时间排序。筛选「只看普通帖子」时按实际发布时间倒序。
- 首批使用独立的混排缓存键，页面与预加载共享。手动下拉绕过缓存，后续各批按当前列表排除已出现的 ID，直接请求云函数。
- 「随机刷新」在广场混排参数上增加 `homeRandom: true`，每批直接向云端请求，不读写首批混排缓存。
- 发布前先部署 `functions/getPostList`（含 `lib/home-posts.js`），再发布客户端。排序、刷新、分页和缓存行为由 `node scripts/test-home-post-ranking.cjs` 覆盖，并纳入 `npm run check:quality`。
