# 诗歌与活动导航

底部导航为“广场 / 诗歌 / 活动 / 我”。活动页占据原读诗页的位置，展示公告、分类入口和近期活动，支持下拉刷新和分页。

诗歌页默认展示原创。顶栏按钮显示当前模式，点击后在原创与读诗之间切换。顶栏下方左侧的乌鸦图标可以打开活动页。

- 原创保留全部诗歌、只看关注和关注用户筛选。
- 读诗展示非原创诗歌，保留诗人筛选，排除匿名投稿。
- 两种模式分别保留本次页面内的列表、分页、筛选和滚动位置；切换后，旧请求与旧筛选的后台更新不覆盖当前内容。
- 新活动红点显示在底部活动入口，进入活动页后清除。
- 已分享的读诗链接和已配置的活动列表链接仍可打开对应内容。读诗分享使用诗歌页的 `mode=reading` 参数。

App 汇文明朝沿用页面 `onReady` 注册和现有诗歌卡片组件，字体路径及绘制名称保持现有约定。
