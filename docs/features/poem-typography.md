# 内容编辑与文字排版

原创诗歌、非原创诗歌、普通帖子和讨论帖子共用单行图标工具栏，沿用圆角和灰色底面；小屏可横向滑动，也可点击左右箭头翻看工具。箭头用几何线条绘制，在灰色栏内居中，点击区域独立于工具列表。支持撤销、重做、字号输入与下拉、A− / A+、加粗、斜体、下划线、删除线、文字颜色与底色、格式刷和清除格式。字号范围为 12–36，调整字号前需选中文字；加粗等开关也可用于接下来输入的文字。发布预览页只展示排版结果。

段落工具提供左对齐、居中、右对齐、两端对齐、增加与减少缩进，以及行距、字距、段前和段后间距。段落格式作用于光标所在或选中的各行，字距作用于选区或后续输入；不会修改整篇内容的基础字号。

格式刷先读取来源选区的格式，开启后再选中目标文字即可应用；同一编辑页内可以跨正文、引用和组诗分块复制格式，再次点击取消。清除格式恢复基础字号（默认 14），移除选区的字符格式与所在段落的格式，其他文字保留原样。

编辑页的返回和下一步按钮放在独立的底部操作区，正文与字数提示始终位于按钮上方。长文在编辑区内滚动，组诗和讨论在分块区域滚动。

讨论右侧工具栏的双引号图标可直接新增引用段，并滚动到新段落；段落右上角的添加菜单可在指定位置插入正文或引用。正文和引用各有独立编辑器，分别保留 1500 字和 500 字上限。正文与引用的格式随草稿、发布、预览及重新编辑一同保存，列表、个人页和详情均按对应格式展示。

组诗各首分别编辑，可以为不同诗句设置不同格式。样式随内容一同编辑：在前方插入、删除文字后，样式继续跟随原来的文字。编辑器保留行首空格、诗节空行和末尾换行，正文仍为纯文本；排版使用独立的范围数据保存。

## 数据与展示

- `poemFontSize`：正文基础字号，默认 14，保留已有作品的基础字号。
- `poemTextStyles`：格式范围数组，每项包含 `start`、`end` 与格式属性。位置按正文 UTF-16 下标计算，`end` 不包含在范围内。
- 字符属性为 `fontSize`、`bold`、`italic`、`underline`、`strike`、`color`、`backgroundColor`、`letterSpacing`。字号和字距按编辑时的 px 保存，颜色为十六进制值。
- 段落属性为 `align`、`lineHeight`、`marginTop`、`marginBottom`、`indent`，附在该行的换行分隔符上；最后一行使用 `[content.length, content.length + 1)` 记录编辑器必需的末尾分隔符。行距为倍数，段前后间距为 px，缩进每级为 3 em，最多四级。
- 组诗各个 `seriesBlocks` 保存自己的 `poemTextStyles`，合并正文的样式按块内容偏移计算。
- 普通内容继续复用 `poemFontSize`、`poemTextStyles` 存储格式。讨论的 `sentenceGroups` 另存 `commentTextStyles`（正文）、`sentenceTextStyles`（换行连接的引用）与基础字号；现有文本整理会同步重定位范围。用于搜索和分享的合并正文另计算整体格式范围。

自动草稿、云端草稿、预览、新建发布和作品修改保留这些字段。诗歌列表、活动诗歌卡片、作品集和详情使用同一分段文字组件。读者的阅读字号设置继续对基础文字和局部文字同比放大。旧作品没有局部样式时沿用原有文字展示。

分享图片按各段字号、粗斜体和字距测量、换行和绘制，保留文字颜色、底色、下划线、删除线、缩进和对齐。行高由该行最大字号与行距决定，段前后间距按编辑字号等比换算。两端对齐只展开自动换行的非末行。分享面板的字号设置按比例缩放整张图片中的文字，局部大小关系保留。

正文使用 uni-app 的 [editor](https://uniapp.dcloud.net.cn/component/editor.html) 和 [EditorContext](https://uniapp.dcloud.net.cn/api/media/editor-context.html)，通过 Delta 在纯文本与字号范围之间转换。H5 使用项目依赖中的 Quill 1.3.7，不依赖远程脚本加载；App 和微信小程序使用各自的 editor 组件。
