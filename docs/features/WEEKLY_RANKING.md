# 本周热榜

自 2026-09-09 起，本周热榜由 `getWeeklyContent` 在查询时自动计算。

- 时间范围为查询时刻往前 168 小时，包含起止时刻，以诗歌 `createTime` 为准。
- 范围内所有未隐藏的诗歌参与排名，包括原创和非原创；分页查询全部候选，不设 500/1000 首截断。
- 热度延续现有规则：点赞数 × 3 + 评论数 × 2 + 浏览数。互动统计沿用累计口径；七天限制针对发布时间。
- 同分时新发布的优先，时间也相同时按作品 ID 排序。
- 首页展示前 10 首，热榜详情展示前 20 首，两者使用相同计算逻辑。
- 无需创建、发布周刊或手动生成热榜。周刊统计周期、精选配置和历史 `rankingSnapshot` 不参与本周热榜计算。
- 最近七天没有诗歌时返回空榜，不使用历史快照或前端示例作品补位。
- 旧版管理接口和历史快照字段保留兼容；新版管理页面移除“生成热榜”入口。

验证命令：`node scripts/test-weekly-ranking.cjs`、`node scripts/test-weekly-home.cjs`、`npm run check:quality`、`npm run build:app`。
