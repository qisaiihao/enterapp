## 功能概述

当用户在小程序中使用 Poem ID + 密码登录时，如果检测到当前微信未绑定到该账号，系统会弹出询问弹窗，让用户选择是否将账号绑定到当前微信。

### V2 版本特性（当前版本）

- ✅ 在 user 表添加 `wechatOpenId` 字段记录绑定关系
- ✅ 不修改原有 `_openid`，保持数据完整性
- ✅ 绑定操作轻量快速（仅更新一条记录）
- ✅ 数据更安全，可跨端共享
- ✅ 支持解绑和重新绑定

## 实现原理

### 1. 登录流程

#### Poem ID 登录流程

```
用户输入 Poem ID 和密码
    ↓
调用 loginWithCredentials 验证身份
    ↓
检查当前微信 openid 是否与账号的 wechatOpenId 不同
    ↓
    ├─ 相同 → 直接登录
    └─ 不同 → 显示绑定微信弹窗
              ↓
         ├─ 确认绑定 → 调用 bindWechatToAccount
         │              ↓
         │         更新 wechatOpenId 字段
         │              ↓
         │         使用新 openid 登录
         │
         └─ 跳过 → 使用原有 openid 登录
```

#### 微信登录流程

```
用户点击微信授权登录
    ↓
调用 loginWithWechat 云函数
    ↓
优先查找 wechatOpenId 匹配的账号
    ↓
    ├─ 找到 → 使用该账号登录（跨账号登录）
    │
    └─ 未找到 → 查找 _openid 匹配的账号
                ↓
                ├─ 找到 → 使用该账号登录
                └─ 未找到 → 自动创建新账号
```

### 2. 绑定流程

用户点击"确认绑定"后：

1. 调用 `bindWechatToAccount` 云函数（forceRebind: false）
2. 验证用户身份（poemId）
3. 检查该微信是否已绑定到其他账号
4. 如果未绑定，直接更新 user 表的 `wechatOpenId` 字段
5. 如果已绑定，返回 `WECHAT_ALREADY_BOUND` 错误和已绑定账号信息
6. 前端显示解绑确认弹窗，告知用户已绑定的账号
7. 用户确认后，再次调用云函数（forceRebind: true）
8. 云函数先解绑旧账号，再绑定到新账号
9. 返回绑定结果
10. 前端更新本地缓存
11. 跳转到主页

### 3. 跳过绑定

用户点击"跳过"后：
1. 使用原有的 openid 完成登录
2. 不更新数据库
3. 跳转到主页

### 4. 数据访问机制（重要）⚠️

**问题**：用户绑定微信后，如何确保访问原有数据？

**解决方案**：
1. 绑定成功后，前端设置 `globalData.openid = result.openid`（原有的 `_openid`）
2. 前端调用云函数时，拦截器自动注入 `data.openid = globalData.openid`
3. 云函数优先使用 `event.openid`（前端传递的），而不是 `wxContext.OPENID`（当前微信的）
4. 因此，所有数据访问都使用原有的 `_openid`，确保数据访问正常

**关键代码**：

前端（`pages/login/login.vue`）：
```javascript
completeBindWechat(result) {
    app.globalData.openid = result.openid; // 使用原有的 _openid
    uni.setStorageSync('userOpenId', result.openid);
}
```

前端拦截器（`main.js`）：
```javascript
const data = Object.assign({}, options.data || {});
if (openid) {
    data.openid = openid; // 自动注入 globalData.openid
}
```

云函数（通用模式）：
```javascript
const openid = event.openid || wxContext.OPENID;
// 优先使用 event.openid（前端传递的原有 openid）
```

**数据流转**：
```
用户绑定微信
    ↓
前端设置 globalData.openid = 原有的 _openid
    ↓
调用云函数（如 createPost）
    ↓
拦截器注入 data.openid = globalData.openid
    ↓
云函数接收 event.openid（原有的 _openid）
    ↓
使用原有 _openid 查询/更新数据
    ↓
数据访问正常 ✅
```

## 云函数说明

### bindWechatToAccount（核心云函数）

**路径**: `functions/bindWechatToAccount/index.js`

**参数**:
- `poemId` (string): 用户的 Poem ID
- `forceRebind` (boolean): 是否强制重新绑定（可选，默认 false）

**返回值**:

```javascript
// 成功
{
  success: true,
  message: '绑定成功',
  isRebind: false
}

// 失败（微信已绑定其他账号）
{
  success: false,
  message: '该微信已绑定到其他账号',
  code: 'WECHAT_ALREADY_BOUND',
  boundAccount: {
    poemId: 'xxx',
    nickName: 'xxx'
  }
}

// 重新绑定成功
{
  success: true,
  message: '绑定成功',
  isRebind: true
}
```

**安全机制**:
- 自动获取当前微信 openid
- 验证用户身份（poemId 必须存在）
- 检查微信是否已绑定到其他账号
- 如果已绑定且 forceRebind=false，返回已绑定账号信息
- 如果已绑定且 forceRebind=true，先解绑旧账号再绑定新账号
- 只更新 `wechatOpenId` 字段，不修改其他数据

**核心逻辑**:

```javascript
// 首次绑定（forceRebind: false）
if (existingBindRes.data.length > 0 && !forceRebind) {
  // 返回已绑定账号信息
  return {
    success: false,
    code: 'WECHAT_ALREADY_BOUND',
    boundAccount: {
      poemId: oldUser.poemId,
      nickName: oldUser.nickName
    }
  };
}

// 强制重新绑定（forceRebind: true）
if (existingBindRes.data.length > 0 && forceRebind) {
  // 先解绑旧账号
  await db.collection('users').doc(oldUser._id).update({
    data: {
      wechatOpenId: db.command.remove()
    }
  });
  
  // 再绑定到新账号
  await db.collection('users').doc(user._id).update({
    data: {
      wechatOpenId: wechatOpenId
    }
  });
}
```

### loginWithWechat（优化版）

**优化内容**:
1. 优先查找 `wechatOpenId` 匹配的账号
2. 如果找到绑定账号，使用该账号登录
3. 支持跨 openid 登录（数据共享）

**查询顺序**:
```javascript
// 1. 优先查找绑定的账号
db.collection('users').where({ wechatOpenId: OPENID })

// 2. 查找原有账号
db.collection('users').where({ _openid: OPENID })

// 3. 都没找到，创建新账号
```

### loginWithCredentials（保持不变）

继续检测 openid 变化，返回 `needBindWechat` 标记。

**返回值**:
```javascript
{
  success: true,
  userInfo: {...},
  openid: 'original_openid',
  currentOpenid: 'current_wechat_openid',
  needBindWechat: true  // 需要绑定
}
```

## 前端实现

### 关键数据字段

```javascript
data() {
  return {
    showBindWechatModal: false,      // 绑定微信弹窗
    showRebindConfirmModal: false,   // 解绑确认弹窗
    isBindingWechat: false,          // 绑定中状态
    pendingLoginResult: null,        // 暂存的登录结果
    boundAccountInfo: null           // 已绑定的账号信息
  }
}
```

### 关键方法

#### 1. 检测是否需要绑定

```javascript
handleLoginResult(result) {
  if (result.needBindWechat) {
    this.pendingLoginResult = result;
    this.showBindWechatModal = true;
  } else {
    // 直接完成登录
    this.completeLogin(result);
  }
}
```

#### 2. 绑定微信

```javascript
async handleBindWechat() {
  this.isBindingWechat = true;
  
  const bindResult = await this.callCloudFunction('bindWechatToAccount', {
    poemId: poemId,
    forceRebind: false
  });
  
  if (bindResult.result.code === 'WECHAT_ALREADY_BOUND') {
    // 显示解绑确认弹窗
    this.boundAccountInfo = bindResult.result.boundAccount;
    this.showRebindConfirmModal = true;
  } else if (bindResult.result.success) {
    this.completeBindWechat(result);
  }
  
  this.isBindingWechat = false;
}
```

#### 3. 确认重新绑定

```javascript
async confirmRebind() {
  const rebindResult = await this.callCloudFunction('bindWechatToAccount', {
    poemId: poemId,
    forceRebind: true
  });
  
  if (rebindResult.result.success) {
    this.completeBindWechat(result);
  }
}
```

#### 4. 跳过绑定

```javascript
skipBindWechat() {
  const result = this.pendingLoginResult;
  app.globalData.openid = result.openid;
  // ... 完成登录，跳转到主页
}
```

## 使用场景

### 场景 1：跨设备登录

用户 A 在自己的微信 A 中用 Poem ID 注册了账号（_openid = A），后来在朋友的手机（微信 B）上用账号密码登录。
- 系统询问是否绑定到微信 B
- 用户确认后，`wechatOpenId = B`
- 下次用微信 B 登录时，直接登录到该账号
- 原有数据（_openid = A）保持不变

### 场景 2：数据共享

用户在 H5 端用 Poem ID 注册（_openid = H5_xxx），后来在小程序用微信登录。
- 用 Poem ID 登录小程序，绑定微信（wechatOpenId = WX_xxx）
- 下次用微信登录小程序，直接登录到该账号
- H5 和小程序数据完全共享

### 场景 3：更换手机/微信已绑定其他账号

用户更换了新手机，使用新的微信号登录旧账号。
- 用 Poem ID 登录，系统询问是否绑定到新微信
- 检测到该微信已绑定到其他账号（如：test_user）
- 显示解绑确认弹窗，告知用户已绑定的账号信息
- 用户确认后，系统先解绑旧账号，再绑定到当前账号
- 绑定成功，新微信可以直接登录该账号
- 旧账号（test_user）将无法使用该微信登录

## 常见问题

### Q1: 绑定后，原有数据会丢失吗？
A: 不会。V2 版本不修改原有 `_openid`，只是添加了 `wechatOpenId` 字段。

### Q2: 旧用户需要重新绑定吗？
A: 不需要。旧用户可以继续使用原有方式登录，也可以选择绑定微信。

### Q3: 一个微信可以绑定多个账号吗？
A: 不可以。一个微信只能绑定一个账号，确保数据安全。

### Q4: 绑定后可以解绑吗？
A: 可以。当用户尝试将微信绑定到其他账号时，系统会提示解绑旧账号并重新绑定。

### Q5: 绑定失败怎么办？
A: 检查云函数日志，常见原因：
- 微信已绑定到其他账号
- 网络问题
- 云函数权限问题

### Q6: 与旧版本（V1）有什么区别？
A: 
- V1：批量修改所有数据的 `_openid`，耗时长，不可逆
- V2：只添加 `wechatOpenId` 字段，快速安全，可扩展

## 注意事项

### 数据访问机制
- ✅ 绑定后，前端 `globalData.openid` 保持为原有的 `_openid`
- ✅ 云函数调用时，拦截器自动注入原有的 openid
- ✅ 云函数优先使用 `event.openid`（前端传递的），确保数据访问正常
- ⚠️ 不要在云函数中直接使用 `wxContext.OPENID`，应该使用 `event.openid || wxContext.OPENID`

### 数据安全
- ⚠️ 一个微信只能绑定一个账号
- ⚠️ 绑定后，该微信将始终登录到该账号
- ⚠️ 不修改原有 _openid，保持数据完整性
- ⚠️ 解绑操作会移除旧账号的 `wechatOpenId` 字段
- ⚠️ 旧账号将无法使用该微信登录（除非重新绑定）

### 性能优化
- ✅ 建议添加数据库索引提高查询性能
- ✅ 定期检查云函数日志
- ✅ 监控绑定成功率

### 用户体验
- ✅ 绑定前明确告知用户
- ✅ 明确告知用户已绑定的账号信息
- ✅ 警告用户解绑的后果
- ✅ 允许用户跳过绑定或取消操作
- ✅ 绑定成功后给予明确提示

### 兼容性
- ✅ 兼容旧数据（没有 wechatOpenId 的用户）
- ✅ 不影响现有功能
- ✅ 平滑升级，无需数据迁移
- ✅ 仅小程序环境生效，H5 和 App 不受影响

### 云函数日志

- 在云开发控制台 -> 云函数 -> 日志
- 筛选 `bindWechatToAccount` 和 `loginWithWechat`
- 检查是否有错误日志

### 关键日志标记

- `🔍` - 调试信息
- `✅` - 成功操作
- `⚠️` - 警告信息
- `❌` - 错误信息
