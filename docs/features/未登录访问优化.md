# 未登录访问优化

## 概述

为了提升用户体验，现在允许未登录用户访问小程序的主要浏览页面，只在需要登录的操作时才提示登录。

## 修改内容

### 1. 全局登录验证逻辑修改

**文件**: `App.vue`

- 修改 `isAllowedPageForUnauthenticated()` 方法，现在允许所有页面未登录访问
- 移除强制重定向到 splash 页面的逻辑
- 保留后台登录流程，但不阻塞用户访问

### 2. Splash 页面修改

**文件**: `pages/splash/splash.vue`

- 移除微信小程序环境下的强制登录验证
- 允许未登录用户直接进入诗歌广场
- 保留后台静默登录尝试

### 3. 新增认证辅助工具

**文件**: `utils/authHelper.js`

提供统一的登录检查和提示功能：

- `isUserLoggedIn()`: 检查用户是否已登录
- `getCurrentUser()`: 获取当前用户信息
- `requireLogin(options)`: 要求用户登录的通用方法
- `checkLoginOrPrompt(options)`: 检查登录状态，如果未登录则提示登录
- `requireLoginDecorator(fn, options)`: 装饰器函数，为需要登录的方法添加登录检查

### 4. 云函数调用优化

**文件**: `utils/cloudCall.js`

- 在需要登录时使用统一的登录提示
- 动态导入 authHelper 避免循环依赖

### 5. 页面级登录检查更新

以下页面已更新为使用新的认证辅助工具：

- **发帖页面** (`pages-publish/add/add.vue`): 发帖前检查登录
- **个人主页** (`pages/profile/profile.vue`): 访问个人主页时检查登录
- **收藏夹** (`pages-content/favorite-folders/favorite-folders.vue`): 查看收藏夹时检查登录

## 用户体验改进

### 允许未登录访问的页面

- 诗歌广场 (`pages/poem-square/poem-square.vue`)
- 首页广场 (`pages/index/index.vue`)
- 山页面 (`pages/mountain/mountain.vue`)
- 帖子详情页 (`pages/post-detail/post-detail.vue`)
- 搜索页面 (`pages-tools/search/search.vue`)
- 其他浏览类页面

### 需要登录的操作

- 发布帖子
- 点赞/取消点赞
- 评论
- 收藏
- 查看个人主页
- 查看收藏夹
- 关注/取消关注
- 其他个人数据相关操作

## 技术实现

### 登录检查策略

1. **页面级检查**: 在需要登录的页面的 `onLoad` 生命周期中检查
2. **操作级检查**: 在具体操作（如点赞、评论）时通过 `cloudCall` 的 `requireAuth` 参数检查
3. **统一提示**: 使用 `authHelper.js` 提供的统一登录提示

### 兼容性

- 支持所有平台（微信小程序、H5、APP）
- 向后兼容现有的登录逻辑
- 不影响已登录用户的使用体验

## 测试建议

### 未登录用户测试

1. 清除小程序缓存或使用新设备
2. 直接访问诗歌广场，确认可以正常浏览
3. 尝试点赞，确认会提示登录
4. 尝试访问个人主页，确认会提示登录
5. 尝试发帖，确认会提示登录

### 已登录用户测试

1. 确认所有功能正常工作
2. 确认登录状态在页面间正确传递
3. 确认退出登录后回到未登录状态

## 注意事项

1. 某些云函数仍然需要 `requireAuth: true` 参数来确保安全性
2. 个人数据相关的页面和操作必须要求登录
3. 浏览类功能应该允许未登录访问以提升用户体验
4. 登录提示应该友好且不打断用户的浏览体验
