# 管理功能使用指南

## 功能概述

管理功能为 poemId 为 `qisaihao` 的用户提供了后台管理能力，包括：

1. **管理帖子**：查看所有帖子、删除帖子、更改帖子类型
2. **管理诗人**：删除错误创建的诗人主页
3. **反馈建议**：查看用户提交的反馈和建议，标记已处理或删除
4. **找回密码**：通过昵称或 poemId 查询用户密码

## 访问入口

管理入口位于个人主页的侧边抽屉栏中：

1. 打开个人主页（我的）
2. 点击左上角的菜单图标，打开侧边抽屉
3. 如果你的 poemId 是 `qisaihao`，会看到"管理"按钮
4. 点击进入管理中心

## 功能详解

### 1. 管理帖子

**路径**：管理中心 → 管理帖子

**功能**：
- 查看所有用户发布的帖子列表
- 支持下拉加载更多
- 每个帖子显示：标题、内容预览、作者、发布时间、当前类型
- 点击帖子可进入详情页查看完整内容

**操作**：
- **更改类型**：点击"更改类型"按钮，选择新的帖子类型
  - 普通帖子（normal）
  - 原创诗歌（original）
  - 非原创诗歌（non-original）
  - 讨论（discussion）
  - 弹窗会显示当前类型，并高亮当前选项
- **删除帖子**：点击"删除"按钮，二次确认后删除帖子及其相关评论和收藏

### 2. 管理诗人

**路径**：管理中心 → 管理诗人

**功能**：
- 查看所有诗人主页列表
- 显示诗人名称、头像、简介、作品数量、更新时间
- 支持下拉刷新和上拉加载更多

**使用场景**：
当用户错误地将原创诗歌发布为非原创诗歌时，系统会自动创建一个诗人主页。这个功能允许管理员删除这些错误创建的诗人主页。

**操作**：
- **查看主页**：点击"查看主页"按钮或点击诗人信息区域，跳转到诗人主页查看详情
- **删除诗人**：点击"删除"按钮，确认后删除诗人主页
  - 删除后无法恢复
  - 该诗人的作品不会被删除
  - 如果用户再次访问该诗人，系统会自动重新创建主页

**注意事项**：
- 删除诗人主页不会删除该诗人的作品
- 删除后，如果有用户访问该诗人的作品，系统会自动重新创建诗人主页
- 建议在删除前先查看诗人主页，确认是否为错误创建

### 3. 反馈建议

**路径**：管理中心 → 反馈建议

**功能**：
- 查看所有用户提交的反馈和建议
- 显示反馈内容、提交用户、提交时间、处理状态
- 支持查看反馈中的图片（点击可预览）
- 支持下拉刷新和上拉加载更多

**操作**：
- **标记已处理**：点击"标记已处理"按钮，将反馈标记为已处理状态
  - 已处理的反馈会显示绿色"已处理"标签
  - 系统会自动通知用户反馈已被处理
- **删除反馈**：点击"删除"按钮，确认后删除反馈记录
  - 删除后无法恢复
  - 相关图片也会被删除

**状态说明**：
- 🟡 待处理：用户刚提交的反馈
- 🟢 已处理：管理员已标记处理的反馈

### 4. 找回密码

**路径**：管理中心 → 找回密码

**功能**：
- 通过昵称或 poemId 搜索用户
- 显示用户的昵称、poemId 和密码
- 支持一键复制密码

**使用方法**：
1. 在搜索框输入用户的昵称或 poemId
2. 点击"搜索"按钮
3. 查看搜索结果
4. 点击"复制密码"按钮复制密码到剪贴板

## 权限验证

- 管理功能仅对 poemId 为 `qisaihao` 的用户开放
- 前端通过 userInfo.poemId 判断是否显示管理入口
- 后端云函数通过查询数据库验证用户的 poemId
- 非管理员用户无法访问管理功能，即使知道页面路径

## 技术实现

### 前端页面

- `pages-admin/admin-menu/admin-menu.vue`：管理中心首页
- `pages-admin/admin-posts/admin-posts.vue`：管理帖子页面
- `pages-admin/poet-management/poet-management.vue`：管理诗人页面
- `pages-admin/feedback-list/feedback-list.vue`：反馈建议页面
- `pages-admin/password-recovery/password-recovery.vue`：找回密码页面

### 云函数

- `functions/adminManager/index.js`：管理功能云函数
  - `getAllPosts`：获取所有帖子列表
  - `updatePostType`：更新帖子类型
  - `deletePost`：删除帖子
  - `getPoetList`：获取诗人列表
  - `deletePoet`：删除诗人
  - `getUserPassword`：查询用户密码

- `functions/feedbackManager/index.js`：反馈管理云函数（已有，已更新权限验证）
  - `getFeedbackList`：获取反馈列表
  - `markAsProcessed`：标记反馈已处理
  - `deleteFeedback`：删除反馈

### 侧边栏组件

- `pages/profile/Sidebar.vue`：个人主页侧边栏
  - 添加了 `isAdmin` 计算属性
  - 添加了管理入口按钮
  - 添加了 `navigateToAdmin` 方法

## 安全注意事项

1. **权限控制**：
   - 云函数会验证用户的 poemId
   - 前端隐藏入口只是 UI 层面的保护
   - 真正的权限验证在云函数中进行

2. **敏感操作**：
   - 删除帖子和反馈操作不可恢复
   - 建议在删除前再次确认

3. **密码安全**：
   - 密码查询功能仅供管理员使用
   - 不要将密码泄露给其他用户

4. **反馈处理**：
   - 及时处理用户反馈，提升用户体验
   - 标记已处理后会通知用户

5. **诗人管理**：
   - 删除诗人主页不会删除作品
   - 删除后系统可能会自动重新创建
   - 建议先查看诗人主页确认是否需要删除
