# 黑白灰交互控件

本次将此前 `#9ed7ee` 对应的文字、背景、边框及半透明阴影统一为登录页和中部弹窗的黑白灰风格，并同步整理相关标签推荐、搜索建议、发布引用区和字体管理控件中的蓝色。

## 样式规则

- 主操作：浅色主题为 `#333333` 底、白字；深色主题为 `#f4f1ea` 底、`#27272c` 字。主按钮采用胶囊圆角，独立操作按钮至少 88rpx 高。
- 标签、筛选和排序：未选中使用浅灰/炭灰底，选中使用反色和更明确的字重。紧凑标签保留与内容密度匹配的尺寸。
- 输入、上传和拖拽：使用中性描边和灰色焦点环；去除蓝色光晕。诗句高光使用灰底与侧边标记，作品选择保留勾选图标。
- 交互反馈：按钮按下降低透明度；保留禁用态、选中态及既有交互事件。
- 拼贴：操作按钮可换行，词块不随容器高度拉伸，保证小屏可读。

共用颜色在 `utils/theme.js` 的 `--app-control-accent-*`、`--app-control-soft-bg`、`--app-control-border`、`--app-control-focus-ring` 和 `--app-link-color` 中定义。深色主题的对应控件也使用中性色，避免局部金色规则覆盖。诗歌内容自身的配色、字体加载及 Canvas 绘制不属于本次调整。
