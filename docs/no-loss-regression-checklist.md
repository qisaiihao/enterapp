# 无损回归清单

## 功能一致性

- [ ] Loading 显示/关闭时机与改造前一致。
- [ ] Toast 文案和触发条件与改造前一致。
- [ ] 下拉刷新会重置分页并停止刷新动画。
- [ ] 触底分页追加结果且不会重复。
- [ ] 乐观更新失败时可回滚。

## 缓存一致性

- [ ] `invalidate*` 在对应操作后仍生效。
- [ ] `shouldRefresh*` 标记消费语义不变。
- [ ] 主页/详情/个人页跨页数据刷新一致。

## 权限一致性

- [ ] 未登录态提示一致。
- [ ] 需鉴权接口未被页面绕过。
- [ ] 管理员能力入口与校验逻辑一致。
