# 重构提交清单

## 提交前确认

- [ ] 本次改动不改变云函数协议（函数名/action/入参/返回字段）。
- [ ] 页面不再直接解析 `res.result`（本次改动涉及页面必须达成）。
- [ ] 重复逻辑已抽到 `api-cache` / `utils` / `components`。
- [ ] 新增中文文案可读，无乱码字符。
- [ ] 关键逻辑包含必要注释（仅在复杂处）。

## 检查命令

```bash
npm run check:encoding
npm run check:syntax
npm run check:quality
```
