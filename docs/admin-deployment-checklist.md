# 管理功能部署清单

## 📋 部署前检查

- [ ] 确认当前用户的 poemId 为 `qisaihao`
- [ ] 确认云开发环境已配置
- [ ] 确认有云函数上传权限

## 🚀 部署步骤

### 1. 上传云函数

**方式一：使用 HBuilderX**
1. 右键点击 `functions/adminManager` 文件夹
2. 选择"上传部署"
3. 等待上传完成

**方式二：使用云开发控制台**
1. 登录腾讯云开发控制台
2. 进入云函数管理
3. 创建新函数 `adminManager`
4. 上传 `functions/adminManager/index.js` 和 `package.json`
5. 安装依赖并部署

### 2. 验证云函数

在云开发控制台测试云函数：

```json
{
  "action": "getAllPosts",
  "page": 0,
  "pageSize": 10
}
```

预期返回：
```json
{
  "success": true,
  "posts": [...]
}
```

### 3. 前端部署

1. 确认 `pages.json` 已更新（已完成）
2. 确认 `Sidebar.vue` 已更新（已完成）
3. 编译项目
4. 上传到微信小程序/发布 H5

## 🔍 问题排查

### 问题1：管理入口不显示

**可能原因**：
- userInfo.poemId 未正确获取
- Sidebar 组件未正确更新

**解决方法**：
1. 检查 console 输出的 userInfo
2. 确认 poemId 字段存在且值为 'qisaihao'
3. 重新编译项目

### 问题2：云函数调用失败

**可能原因**：
- 云函数未正确上传
- 权限验证失败
- 数据库连接问题

**解决方法**：
1. 在云开发控制台查看云函数日志
2. 确认云函数已部署且状态正常
3. 检查数据库权限配置

### 问题3：帖子列表为空

**可能原因**：
- 数据库中没有帖子
- 查询条件错误

**解决方法**：
1. 在云开发控制台查看 posts 集合
2. 确认有数据存在
3. 检查云函数日志

## 📝 回滚方案

如果部署后出现问题，可以按以下步骤回滚：

1. **回滚云函数**：
   - 在云开发控制台删除 adminManager 云函数
   
2. **回滚前端代码**：
   ```bash
   git checkout HEAD -- pages/profile/Sidebar.vue
   git checkout HEAD -- pages.json
   ```
   
3. **删除管理页面**：
   ```bash
   rm -rf pages-admin
   ```
