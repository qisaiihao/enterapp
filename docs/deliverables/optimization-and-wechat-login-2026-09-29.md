# 收藏、图片链接与微信登录优化交付

日期：2026-09-29。用户要求按收藏一致性、图片链接优化、简单问题、微信绑定登录的顺序处理；微信登录改造前先 Git 存档。最低兼容客户端为 1.7.0。

## 已完成：收藏一致性

统一成功写入通知、账号隔离、分页失效和页面刷新。处理旧请求晚返回、多收藏夹中的同帖记录、删除收藏夹提示不符合实际行为的问题。详见 [收藏一致性](../features/favorite-consistency-2026-09-29.md)。客户端修改，无需更新收藏云函数。

## 已完成：图片链接统一解析

五个列表接口支持 `rawImages: true`；新版客户端统一换链并保留文件 ID，1.7.0 继续收到原 HTTPS 响应。详见 [图片链接统一解析](../features/post-image-links-2026-09-29.md)。服务端源码已修改，尚未部署；需部署五个列表函数并发布客户端后取得完整收益。

## 已完成：范围明确的小问题

- 首页、标签、讨论、发现接口失败时抛错，避免把故障缓存成空列表并显示“没有更多”。成功结果仍按原 TTL 复用。
- 通用列表强制刷新也经过缓存管理器，较慢的旧刷新不能覆盖较新的结果。
- 通用云调用不再把成功响应整体打印到客户端日志。
- 版本测试严格校验当前资源版 `1.7.1 / 171`；最低支持版 `1.7.0` 的更新选择器用例继续保留。未修改 manifest 版本，也未删除或降低原断言要求。
- 将原来单独运行的 `test:login` 纳入 `check:quality`。

新增 `test-feed-cache-retry.cjs` 覆盖四个接口的失败重试、成功缓存和强制刷新竞态。
