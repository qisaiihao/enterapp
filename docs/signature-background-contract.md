# 签名上传与去纸底

更新：2026-09-12。

## 处理入口

- `pages-user/profile-edit/profile-edit.vue` 保留用户确认的原图路径，缓存去底和保留背景两个版本。新选图和切换去底效果先进入候选预览，任务串行访问页面画布，任务编号阻止开关切换、换图和离页后的旧结果写回。
- `utils/signatureImage.js` 负责图片解码和 PNG 导出。H5 使用 DOM Canvas；微信使用页面 2D Canvas；App 使用 `createCanvasContext`、`canvasGetImageData`、`canvasPutImageData` 和 `canvasToTempFilePath`，等待每一步回调后再继续。
- `utils/signatureMatting.js` 只处理 RGBA 像素，不访问平台或云服务。
- `utils/shareCanvas.js` 仅转换云文件地址并加载签名，不再次去底。上传预览、帖子显示和分享使用同一图片，关闭去底的选择也会保留。

## 图像约定

1. 选图请求原图，不预先做 JPEG 质量压缩。去底在最长边不超过 1024px 的画布上完成，再导出最长边不超过 600px 的 PNG；不放大、不裁切，保留宽高比例。
2. 已经包含透明或半透明像素的图片跳过去底，保留原有笔画及边缘。最终如需缩小，仍进行一次正常图像缩放。
3. 边缘带多点取样，并对候选纸张颜色取中位数，排除深色笔画干扰。仅对以浅色、低饱和纸张为主的背景自动处理。
4. 按网格估计局部纸张颜色，再插值以补偿缓慢变化的阴影。用估计的墨色深度计算连续透明度，再通过 `C = alpha * F + (1-alpha) * B` 反解前景颜色，减少白边，保留黑、灰、蓝、红色墨水。
5. 接近纸张噪声的微弱色差会平滑消除；不做腐蚀或按面积删除连通域，避免删掉细线和独立点画。
6. 关闭去底时只缩放、导出 PNG。导出失败或识别结果全透明时，在确认预览中明确说明当前为原图，不将空图当成优化成功。

## 上传确认

- 处理结束后使用 `AppDialog` 展示原图和处理结果，棋盘格用于辨认透明区域；按钮为“使用签名”和“取消”。
- 未确认的候选图不修改当前签名，不进入资料审核或上传流程。确认后将候选图放入资料表单，用户点击页面 enter 时随资料保存上传。
- 取消、App 返回键或预览图片加载失败时丢弃候选图，保留原有签名及去底设置，包括已经确认但尚未保存的签名。后续返回原签名切换效果时继续复用其缓存。
- 处理中取消或离页会使任务失效，迟到回调不能重新打开预览。等待用户确认期间禁用资料保存；审核期间若签名任务发生变化，也终止本次保存，避免上传尚未审核的新版本。

## 适用范围

适合白纸、浅灰纸、轻微泛黄纸上的签名，以及纸张上的渐变光照。强烈硬阴影、横格纸、复杂彩色背景和极浅铅笔字不保证能自动分离，用户可以关闭去底保留原图。带透明边框但内部仍有不透明纸底的图片也保守跳过，不自动二次抠图。

历史上传文件不会自动改写；需要重新选择原始照片并保存才能应用新算法。历史图片在分享时也使用原文件，不再执行旧的微信专属阈值去白逻辑。

## 验证

- `npm run test:signature`：透明像素、边缘取样污染、黑/蓝/红色笔画及抗锯齿覆盖率、渐变阴影、暖色纸张、独立点画、App 画布调用顺序、失败回退、任务串行、开关缓存和离页取消、微信分享云地址解析。
- `node scripts/test-signature-h5.cjs`：真实浏览器 Canvas 解码、JPEG 输入、透明 PNG、无白边合成及 PNG 尺寸/格式验证。
- `node scripts/test-signature-preview-h5.cjs`：实际页面上的原图/结果预览、确认、取消、返回、失败说明和明暗主题布局，使用本地样例，避免向真实账号上传。
- 修改分享绘制入口后运行 `npm run check:quality`、`npm run build:app`，跨端改动再运行 `npm run build:mp-weixin`，并运行分享卡片颜色回归测试。
- 真机仍需检查：App/微信分别上传白纸照片、透明 PNG、蓝笔签名；切换开关；保存后查看帖子和深色分享卡片；处理中退出页面。自动测试不代替真机验收。

算法参考：[OpenCV 局部阈值与不均匀光照](https://docs.opencv.org/4.13.0/d7/d4d/tutorial_py_thresholding.html)、[W3C Alpha 合成公式](https://www.w3.org/TR/compositing-1/#simplealphacompositing)。App 画布调用参考：[DCloud 像素读取](https://uniapp.dcloud.net.cn/api/canvas/canvasGetImageData)、[像素写入](https://uniapp.dcloud.net.cn/api/canvas/canvasPutImageData.html)。
