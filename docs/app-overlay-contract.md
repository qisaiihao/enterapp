# 共用确认框与操作菜单

确认框使用居中容器，无需键盘输入的自有底部弹窗统一使用帖子操作面板的容器。登录、注册、手机验证码、自定义标签和新建收藏夹/作品集等输入表单保留原有形式；分享图片预览、全屏高光编辑和平台原生选择器保持各自用途。

## 组件与外观

- `components/overlay/AppDialog.vue`：居中确认框，白底黑字、细边框、小圆角；最多支持取消、额外操作、确认三个按钮。危险操作用红字。长说明在内部滚动。
- `components/overlay/AppActionSheet.vue`：底部操作菜单默认使用 `plain`，无标题栏和顶部关闭按钮；共用整行选项、独立取消区、安全区域与进出动画。`title` 用作无障碍标签。
- 两个组件使用系统界面字体，深色模式切换为深底浅字。遮罩统一为 40% 黑色。
- `ActionMenu` 和 `DeleteModal` 都使用 `AppActionSheet` 的 `plain` 样式：无标题栏和顶部关闭按钮、整行居中、可选辅助说明、独立取消区，浅色为白底深字，深色为炭灰底浅字，底部留出安全区域。外层帖子菜单的编辑、组诗合成、隐藏/取消隐藏和删除入口均使用普通文字色；删除面板的“删除帖子”使用适配浅色/深色模式的红字，另有永久删除说明。
- `plain` 菜单以 240ms 从底部滑入、180ms 滑出，遮罩同步淡入淡出；关闭动画完成后再发出操作或取消事件，下一级面板随后展开。关闭期间拦截重复点击和物理返回，外部关闭、重开或卸载会撤销待执行事件。`uni.showActionSheet`、头像和背景操作同样在退出动画后回调。系统减少动态效果设置下缩短视觉动画。
- 发布模式使用整行操作；配色、字体、收藏夹、作品集、默认头像和云提示使用默认插槽保留必要的选择内容。插槽提供 `select(value)`，也可通过组件引用调用 `selectValue(value)`，用于退出动画完成后提交选择。字体实时预览保持原逻辑，底部显示“完成”；提示底部显示“知道了”。其余面板显示“取消”。
- 收藏夹/作品集的“创建”在列表退出后打开原输入表单；取消创建后回到选择列表，接口失败时列表继续显示以便重试。关闭列表直接更新 Vue 状态并触发 `hide`，避免旧 `setData` 对 `propsData` 的读取中断关闭回调。
- 帖子删除面板提供“删除并存为草稿”“仅自己可见”“删除帖子”。存草稿仍在保存成功后删除原帖；“仅自己可见”复用隐藏功能，已隐藏时禁用该项，不会再次切换成公开。原有 `close`、`save-draft`、`confirm` 事件保留，新增 `hide` 事件。
- 头像、背景、收藏夹删除和微信绑定确认继续使用共用确认框。
- 需要等待接口的受控确认框传入 `busy`；处理中禁用按钮，处理结束后允许重试，避免连续点击重复提交。

## 页面接入

每个自有路由页面的模板末尾放置一个 `<app-overlay-host />`，由 uni-app easycom 加载。新增页面时也必须添加；`scripts/test-app-overlays.cjs` 检查 pages.json 中的页面是否接入。

`main.js` 安装 `utils/appOverlay.js` 的适配器与页面生命周期 mixin。现有业务继续调用 `uni.showModal` / `uni.showActionSheet`，不需要重写确认和取消分支。系统权限授权、图片选择等平台功能不拦截。尚无页面的启动阶段和第三方升级页面保留平台弹窗兜底。

适配器支持现有的标题、正文、按钮文字、单按钮提示、输入框和操作列表；普通按钮颜色统一，危险按钮按操作文案标记，不沿用各页面分散的 confirmColor 配色。

## 交互约定

- 同一页面的 API 请求按顺序展示，不能覆盖尚未回答的确认框。
- 确认框默认不允许点击遮罩关闭；已有自绘确认框可用 `closeOnMask` 保留原有行为。底部菜单允许点遮罩、关闭和取消。
- `showCancel: false` 的提示不会被返回键当作确认，也不会通过返回键跳过。
- 有弹层时 App 返回键先处理最上层；发布页的草稿返回拦截优先尊重弹层处理结果。
- `event.from === 'navigateBack'` 的主动导航不由全局弹层拦截；发布页已完成草稿选择后也应先放行主动返回，避免弹窗尚未卸载时吞掉跳转。物理返回仍优先处理弹层。
- 点击结果只提交一次。接口回调保留 `success`、`fail`、`complete`，无回调时返回 Promise；菜单取消走 fail/reject，确认框取消走 success/resolve 的 `cancel: true`。
- 页面隐藏或卸载时，尚未回答的 API 请求以 `fail page closed` 结束，防止确认结果误用到另一个页面。
- 新增有自身 `onBackPress` 的页面时，参照发布页处理 `event.appOverlayHandled`，避免页面退出逻辑覆盖弹窗的返回处理。

## 验证

- `node scripts/test-app-overlays.cjs`：适配器队列、回调、Promise、页面隔离、返回、重复点击、异步重试和页面接入；运行预览删除、注册去登录、管理页面权限与错误提示等 7 处实际弹窗回调，验证确认/取消与操作菜单回调中的主动返回不会被弹层拦截。
- `node scripts/test-publish-back.cjs`：真实 Vue 弹窗回调同步触发返回时，验证发布页工具栏与物理返回、不保存、保存完成后返回及退出草稿清理。
- `node scripts/test-delete-modal.cjs`：删除面板事件映射、隐藏目标、已隐藏保护、草稿保存成功后删除及失败保留原帖。
- `node scripts/test-sheet-motion.cjs`：关闭后触发动作、连续点击/返回、快速重开，以及外部关闭/卸载时撤销待执行动作。
- H5 开发服务启动后执行 `node scripts/test-delete-modal-h5.cjs`：浅色/深色布局、三个操作、已隐藏状态、遮罩与返回键；截图同样保存到系统临时目录的 `enterkey-overlay-review`。
- H5 开发服务启动后执行 `node scripts/test-app-overlays-h5.cjs`；可设置 `H5_URL`、`PUPPETEER_EXECUTABLE_PATH`。测试实际页面上的点击、深色模式和队列，截图写入系统临时目录的 `enterkey-overlay-review`。
- `node scripts/test-bottom-sheets-h5.cjs`：实际选择组件在明暗两种模式下的布局、模式/配色/头像返回值、字体预览、收藏/作品集失败重试、创建表单切换、返回和遮罩关闭，并检查验证码与标签输入仍使用原有表单。数据接口用本地测试替身，避免写入真实账号。
- `npm run check:quality`、`npm run build:app`、`npm run build:mp-weixin`。
- 真机仍需检查 Android/iOS 返回键、键盘弹出时的位置、长内容滚动，以及微信原生控件覆盖层级。App 字体加载路径与 onReady 注册流程未修改。
