### 1.1 功能与服务范围

回车键是一款诗歌创作与分享社区，主要功能模块包括：

1. **账号与登录**：手机号短信验证码登录/注册、账号（Poem ID）+ 密码登录、微信登录、GitHub 授权登录。
2. **内容创作与发布**：单篇诗歌、组诗、讨论帖、拼贴诗，支持图片上传、背景与文字配色；发布后编辑、草稿保存。
3. **社区互动**：帖子详情、评论与回复、点赞（分级）、收藏/作品集、关注与粉丝、站内系统通知。
4. **内容运营**：诗歌周刊（特刊、热榜、主题征稿）、线上活动与公告。
5. **管理与审核**：内容审核、举报受理、帖子删除、发帖禁言、意见反馈处理。

本应用**不提供**即时通信、点对点私信、群组/通讯群组聊天、直播、音视频发布等即时通信类功能；用户之间的互动限于帖子、评论/回复、关注及平台系统通知。

## 三、安全评估逐项情况

### （一）安全管理负责人、信息审核人员及安全管理机构设立情况

运营主体设立内容安全管理小组，实行"负责人负责制 + 审核值守"：

- 安全管理负责人：**黎俊皓**（法定代表人/公司负责人），联系电话 **19928929591**，全面负责内容安全、信息安全与应急处置，为监管对接第一责任人。
- 信息审核人员：由运营团队承担内容审核岗，联系电话 **19928929591**，负责用户发布内容的日常巡查、人工复核与举报受理。
- 安全运维人员：由技术团队承担运维岗，联系电话 **19928929591**，负责服务器与云环境、审核日志、权限与数据安全。

公司建立并执行《内容审核管理制度》《用户举报与投诉处理制度》《安全事件应急预案》《日志留存与协助监管流程》，明确审核范围（帖子、评论、昵称、简介、头像、图片、活动投稿等全部用户可写入口）、处置时限（工作日 12 小时内响应、24 小时内处理）与升级机制（重大违规内容即时下线并留存证据，涉嫌违法犯罪的依法向主管部门报告）。

### （二）用户真实身份核验及注册信息留存措施

平台对用户实行**手机号强制绑定**的实名核验：

1. **强制绑定**：新用户注册及使用发布、评论、点赞等核心功能前，必须完成手机号绑定；未绑定手机号的账号不能发布内容。
2. **短信核验**：手机号绑定与登录均通过短信验证码校验，验证码为 6 位、具备有效期与错误次数限制，验证码与手机号在服务端以事务方式核验并一次性消费，防止重放与暴力猜测。
3. **注册信息留存**：系统在注册事件中记录并长期留存手机号（脱敏存储与展示）、Poem ID、昵称、头像、注册时间、微信/GitHub 等第三方标识及相关设备与网络信息，写入 `users` 等数据表；账号注销时按隐私政策删除或匿名化处理。
4. 同一手机号仅允许绑定一个账号，重复绑定被拒绝，保证身份与账号一一对应。

### （三）用户账号、操作时间、操作类型、网络源地址与目标地址、网络源端口、客户端硬件特征等日志信息，以及发布信息记录的留存措施

平台依托腾讯云开发云函数网关访问日志与业务数据表实现日志留存：

1. **访问与操作日志**：云函数网关对每次调用记录调用者身份（openid）、请求时间、请求类型/操作类型、调用来源 IP 与端口、目标云函数及返回状态，日志留存不少于 6 个月。
2. **业务行为记录**：用户的注册、登录、发帖、编辑、评论、点赞、收藏、关注、举报、反馈等操作均落库并记录操作时间与操作主体（如 `posts`、`comments`、`votes_log`、`view_log`、`moderation_logs`、`post_reports` 等集合）。
3. **发布内容留存**：用户发布的帖子、评论、图片等，即使被管理员屏蔽或删除，原始记录仍在数据库中留存，可追溯发布人、发布时间与内容版本。
4. **终端特征**：客户端在授权范围内采集并上报设备型号、操作系统、网络类型等用于安全风控的特征信息。
5. 上述日志仅授权安全运维与审核人员在必要范围内查询，并支持按时间、账号、内容 ID 进行检索与提取。

### （四）对用户账号与通讯群组名称、昵称、简介、备注、标识，信息发布、转发、评论等服务功能中违法有害信息的防范处置和有关记录保存措施

1. **审核入口全覆盖**：发帖、编辑、评论、回复、用户昵称/简介/签名、头像、拼贴图片、活动投稿等全部用户可写入口统一接入内容审核，审核不通过时阻止写入。
2. **机器审核**：接入腾讯云内容安全服务，对文本调用**文本内容安全（TMS）**、对图片调用**图片内容安全（IMS）**进行检测；命中违规（Block）直接拦截并提示用户，命中疑似（Review）转人工复核，接口异常时按策略阻断写入并告警。
3. **人工审核与处置**：管理员后台可查看全部帖子与评论，对违规内容执行删除/屏蔽，对违规账号执行**发帖禁言**（`postingBanned`）直至恢复；处置动作与操作管理员、时间一并留痕。
4. **记录保存**：内容审核结果写入 `moderation_logs`（记录审核类型、命中标签、置信度、请求标识、时间及脱敏文本），举报与处置写入 `post_reports`；用户发布与评论记录永久保存，后台屏蔽仅前端不可见、后台仍可核查。
5. **通讯群组**：本应用不含用户自建群组/通讯群组功能，不存在群名称、群标识等场景；昵称、简介、备注等资料字段同样纳入审核。

### （五）个人信息保护以及防范违法有害信息传播扩散、社会动员功能失控风险的技术措施

1. **个人信息保护**：
   - 首次启动强制阅读并同意《隐私政策》后方可进入应用，同意前不登录、不上传、不采集，不默认勾选；政策版本更新后老用户需重新确认。
   - 坚持最小必要原则，仅在实现登录、发布、互动等功能所必需的范围内收集手机号、昵称、头像、发布内容等；手机号脱敏展示，用户之间仅可见头像、昵称等公开信息，不可见他人手机号、生日等隐私信息。
   - 全链路 HTTPS 加密传输；敏感字段加密存储；数据库与云存储按最小权限配置访问规则，绑定凭据等敏感集合禁止客户端读写。
   - 提供完整的**账号注销**与个人信息查询、更正、删除路径；注销时删除账号与隐私数据、匿名化保留公开内容。
2. **防范违法有害信息传播扩散与社会动员失控**：
   - 全入口接入腾讯云内容审核，违规内容"先审后发、命中即拦"。
   - 提供**用户举报**入口，用户可就"对他人造成困扰或危害""侵犯权益"等分类举报帖子，举报经服务端去重并推送管理员，管理员在后台受理并选择删帖处理或不处理，处置结果与理由通知举报人。
   - 管理员可对违规账号禁言、屏蔽或删除违规内容；对涉嫌违法犯罪的信息及时固定证据并向主管部门报告。
   - 应用不含即时通信、群组传播、打赏/资金支付等易被用于社会动员的功能，传播路径限于公开帖子与评论，风险可控。

### （六）建立投诉、举报制度，公布投诉、举报方式等信息，及时受理并处理有关投诉和举报的情况

1. **公布渠道**：在《隐私政策》及应用内公布投诉举报方式，包括联系邮箱 **poementer@yeah.net**、"意见反馈"入口及帖内"举报"入口。
2. **制度与流程**：建立《用户举报与投诉处理制度》，对举报与投诉进行分类登记、专人受理、限时处置（一般 12 小时内响应、24 小时内处理完毕）并回复处理结果。
3. **受理与留痕**：用户举报在应用内提交后，系统即时通知管理员；管理员的受理、删帖处理或不处理结果、处理时间与处理人一并写入 `post_reports` 并通知举报人，形成可核查台账。
4. **反馈闭环**：对个人信息相关投诉，承诺在十五个工作日内予以回复。

### （七）建立为监管部门和执法部门依法履职提供技术、数据支持和协助的工作机制的情况

1. **对接机制**：由安全管理负责人作为监管对接第一责任人，接到网信、公安等主管部门依法履职的要求后，核验法律文书与工作证件，履行内部审批后予以配合。
2. **技术支持**：可按账号、手机号（核验后）、内容 ID、时间范围等条件，从云数据库、`moderation_logs`、`post_reports`、访问与操作日志中提取用户注册信息、发布信息与行为记录，并按要求以安全方式提供。
3. **内容处置**：可通过管理员后台对违法有害信息及时屏蔽、删除，对违规账号禁言或处置，并在监管要求下提供处置记录。
4. **数据安全**：对外提供数据遵循最小必要与安全交付原则，做好交接记录与保密管理，涉及个人信息的依法依规处理。
5. 相关工作由安全运维小组负责落实，确保技术、数据支持渠道畅通。
