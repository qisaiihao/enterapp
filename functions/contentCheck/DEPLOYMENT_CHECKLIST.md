# 部署检查清单

在部署微信内容审核组件之前，请确保完成以下步骤：

## 1. 环境配置 ✓

- [ ] 在 `functions/contentCheck/config.json` 中配置 `WECHAT_APPID`
- [ ] 在 `functions/contentCheck/config.json` 中配置 `WECHAT_SECRET`
- [ ] 确认 AppID 和 Secret 来自正确的小程序

## 2. 数据库设置 ✓

- [ ] 创建 `moderation_logs` 集合
- [ ] 创建 `access_tokens` 集合
- [ ] 创建 `moderation_cache` 集合
- [ ] 为 `moderation_logs` 添加 `openid` 索引
- [ ] 为 `moderation_logs` 添加 `createTime` 索引
- [ ] 为 `access_tokens` 添加 `updateTime` 索引
- [ ] 为 `moderation_cache` 添加 `fingerprint` 唯一索引
- [ ] 为 `moderation_cache` 添加 `createTime` TTL 索引（300秒）

## 3. 云函数部署 ✓

- [ ] 上传 `contentCheck` 云函数到云端
- [ ] 安装云函数依赖（`wx-server-sdk`）

## 常见问题

### Q: Token 获取失败怎么办？
A: 检查 `WECHAT_APPID` 和 `WECHAT_SECRET` 是否正确配置。

### Q: 审核一直返回"系统繁忙"？
A: 可能是微信 API 限流，稍后重试。也可能是环境变量未配置。

### Q: 缓存不生效？
A: 检查 `moderation_cache` 集合是否创建，以及 TTL 索引是否配置。

### Q: 日志记录失败？
A: 检查 `moderation_logs` 集合是否创建，以及权限配置是否正确。

## 回滚计划

如果部署后出现严重问题，可以：

1. 在云开发控制台停用 `contentCheck` 云函数
2. 在客户端代码中移除审核调用
3. 恢复到之前的版本
