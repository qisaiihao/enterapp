# 登录方式适配检查报告

## 检查时间
2026-03-05

## 当前登录方式分析

### 现有登录方式

**pages/login/login.vue** 当前支持的登录方式：

1. **Poem ID + 密码登录** ✅
   - 输入 Poem ID 和密码
   - 调用 `loginWithCredentials` 云函数验证
   - 登录成功后可能需要绑定手机号

2. **GitHub OAuth 登录** ❌（小程序不支持）
   - 代码已注释掉
   - 仅支持 H5 和 App 环境
   - 小程序环境会提示不支持

### 

❌ **缺少微信授权登录**
- 小程序环境下没有微信授权登录入口
- 用户只能通过 Poem ID + 密码登录
- 新用户需要先注册才能登录

❌ **用户体验不佳**
- 小程序用户期望使用微信一键登录
- 当前需要记住 Poem ID 和密码
- 没有"忘记密码"功能

## 建议的登录流程

### 小程序环境下的理想登录流程

```
用户打开登录页面
    ↓
显示"微信授权登录"按钮（主要入口）
    ↓
用户点击微信授权登录
    ↓
调用 wx.login 获取 code
    ↓
调用云函数验证用户
    ↓
┌─────────────────────┐
│  用户是否已注册？    │
└─────────────────────┘
    ↓                ↓
   是               否
    ↓                ↓
登录成功          跳转注册页面
    ↓              （自动填充微信信息）
进入主页面              ↓
                   完成注册后登录
```

### 备用登录方式

如果微信授权失败或用户取消：
```
显示"使用 Poem ID 登录"选项
    ↓
用户输入 Poem ID + 密码
    ↓
调用 loginWithCredentials 云函数
    ↓
登录成功/失败
```

#### 2. 添加微信登录逻辑

```javascript
export default {
    data() {
        return {
            poemId: '',
            password: '',
            isLogging: false,
            showPasswordLogin: false, // 小程序环境下控制是否显示密码登录
            // ... 其他数据
        };
    },
    
    computed: {
        canLogin() {
            // #ifdef MP-WEIXIN
            if (!this.showPasswordLogin) {
                return true; // 微信登录始终可用
            }
            // #endif
            return this.poemId.trim() && this.password.trim();
        }
    },
    
    methods: {
        // 微信授权登录
        async loginWithWechat() {
            // #ifdef MP-WEIXIN
            if (this.isLogging) return;
            
            this.isLogging = true;
            uni.showLoading({
                title: '登录中...',
                mask: true
            });
            
            try {
                // 1. 调用 wx.login 获取 code
                const loginRes = await new Promise((resolve, reject) => {
                    wx.login({
                        success: resolve,
                        fail: reject
                    });
                });
                
                if (!loginRes.code) {
                    throw new Error('获取微信登录凭证失败');
                }
                
                // 2. 调用云函数验证用户
                const result = await this.callCloudFunction('loginWithWechat', {
                    code: loginRes.code
                });
                
                console.log('🔍 [微信登录] 云函数返回结果:', result);
                
                if (result.result && result.result.success) {
                    if (result.result.needRegister) {
                        // 需要注册，跳转到注册页面
                        uni.showToast({
                            title: '请先完成注册',
                            icon: 'none',
                            duration: 2000
                        });
                        
                        setTimeout(() => {
                            uni.navigateTo({
                                url: '/pages/register/register?fromWechat=true'
                            });
                        }, 1500);
                    } else {
                        // 登录成功
                        await this.handleLoginResult(result);
                    }
                } else {
                    throw new Error(result.result?.message || '登录失败');
                }
            } catch (error) {
                console.error('❌ [微信登录] 失败:', error);
                
                // 如果是用户拒绝授权，提示使用账号密码登录
                if (error.errMsg && error.errMsg.includes('auth deny')) {
                    uni.showModal({
                        title: '授权失败',
                        content: '您拒绝了微信授权，可以使用 Poem ID 登录',
                        showCancel: true,
                        cancelText: '取消',
                        confirmText: '使用 Poem ID',
                        success: (res) => {
                            if (res.confirm) {
                                this.showPasswordLogin = true;
                            }
                        }
                    });
                } else {
                    uni.showToast({
                        title: error.message || '登录失败，请重试',
                        icon: 'none',
                        duration: 3000
                    });
                }
            } finally {
                uni.hideLoading();
                this.isLogging = false;
            }
            // #endif
        },
        
        // 账号密码登录（保持不变）
        async onLogin() {
            // #ifdef MP-WEIXIN
            if (!this.showPasswordLogin) {
                // 微信登录
                return this.loginWithWechat();
            }
            // #endif
            
            // 账号密码登录（原有逻辑）
            if (!this.canLogin || this.isLogging) {
                return;
            }
            
            // ... 原有的账号密码登录逻辑
        }
    }
};
```

#### 3. 创建微信登录云函数

创建 `functions/loginWithWechat/index.js`:

```javascript
const cloud = require('wx-server-sdk');
cloud.init({
  env: cloud.DYNAMIC_CURRENT_ENV
});

const db = cloud.database();

exports.main = async (event, context) => {
  const { code } = event;
  const wxContext = cloud.getWXContext();
  
  try {
    // 1. 通过 code 换取 openid 和 session_key
    // 注意：这里的 openid 是微信的 openid，不是腾讯云开发的 openid
    const { OPENID, UNIONID } = wxContext;
    
    if (!OPENID) {
      return {
        success: false,
        message: '获取微信用户标识失败'
      };
    }
    
    // 2. 查询用户是否已注册
    const userRes = await db.collection('users')
      .where({
        wechatOpenid: OPENID
      })
      .get();
    
    if (userRes.data.length > 0) {
      // 用户已注册，返回用户信息
      const user = userRes.data[0];
      
      return {
        success: true,
        needRegister: false,
        userInfo: user,
        openid: user._openid,
        isPhoneVerified: user.isPhoneVerified || false
      };
    } else {
      // 用户未注册，需要跳转到注册页面
      return {
        success: true,
        needRegister: true,
        wechatOpenid: OPENID,
        unionid: UNIONID
      };
    }
  } catch (error) {
    console.error('微信登录失败:', error);
    return {
      success: false,
      message: error.message || '登录失败'
    };
  }
};
```
