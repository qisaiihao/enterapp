# 部署检查清单

在部署到生产环境之前，请确认以下所有项目：

## 腾讯云配置检查

- [ ] 已开通腾讯云短信服务
- [ ] 已创建短信应用，获得 SmsSdkAppId：`1401056037`
- [ ] 短信签名已审核通过：`江门市新会区回车键网络`
- [ ] 短信模板已审核通过，模板 ID：`2601313`
- [ ] 已获取 API 密钥（SecretId 和 SecretKey）
- [ ] 短信套餐包余额充足（或已开通按量计费）

## 环境变量配置检查

- [ ] 在 uniCloud 控制台设置了 `TENCENT_SECRET_ID`
- [ ] 在 uniCloud 控制台设置了 `TENCENT_SECRET_KEY`
- [ ] 环境变量值正确无误（无多余空格）

## 配置文件检查

- [ ] `config.json` 中 `provider` 设置为 `"tencentcloud"`
- [ ] `sdkAppId` 为 `"1401056037"`
- [ ] `signName` 为 `"江门市新会区回车键网络"`
- [ ] `templateId` 为 `"2601313"`
- [ ] `region` 为 `"ap-guangzhou"`

## 依赖安装检查

- [ ] 已在 `sendSmsCode` 目录执行 `npm install`
- [ ] `package.json` 中包含 `tencentcloud-sdk-nodejs-sms` 依赖

```bash
# 检查环境变量（在 uniCloud 控制台）

```

## 遇到问题？

1. 查看 [README.md](../sendSmsCode/README.md) 的"常见问题"部分
2. 查看云函数日志获取详细错误信息
3. 确认腾讯云控制台中签名和模板状态
4. 检查环境变量是否正确设置

## 紧急回滚

如果遇到严重问题需要回滚：

1. 修改 `config.json`：
```json
{
  "provider": "unicloud"
}
```

2. 重新部署云函数

3. 验证功能恢复正常
