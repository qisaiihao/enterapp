# 实现计划：短信服务迁移到腾讯云

## 概述

本实现计划将现有的 uniCloud 短信服务迁移到支持多服务商的架构，新增腾讯云 SMS 支持，同时保留原有 uniCloud 实现。系统采用策略模式实现服务商抽象，通过配置实现灵活切换。
